# Studio lighting

`studio_small_09_1k.hdr` — "Studio Small 09" by Sergej Majboroda, from
[Poly Haven](https://polyhaven.com/a/studio_small_09). Licence: CC0 (public
domain, no attribution required). Used as the configurator's image-based
lighting; crisp strip-light highlights are added in code with drei
`Lightformer`s (see `build/components/preview-canvas.tsx`).

The 1K version is deliberately used: it only drives soft lighting and blurred
reflections, so higher resolutions add download weight without visible gain.
